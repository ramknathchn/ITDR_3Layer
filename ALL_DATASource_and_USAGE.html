1. Active Directory (On-Premises Domain Controllers)
[ad_events] & [ad_users]
Target SQL Tables
ad_events, ad_users, ad_gpo_reports
Primary Event Types
Kerberos TGT, Kerberoasting, DCSync, Password Spray (Event 4625)
Executable Rules Executed
46 Executable T-SQL Rules

Relational Table Schema ([ad_events]):

Column NameData TypeNullableDescription
idINT (PK IDENTITY)NoPrimary auto-increment key
event_idINTNoWindows Event ID (4624, 4625, 4768, 4769, 5136)
timestampDATETIME2NoEvent timestamp UTC
event_typeVARCHAR(100)NoEvent Type (LogonFailed, Kerberoast, DCSync)
identity_userVARCHAR(150)NosAMAccountName / Target Identity User
source_ipVARCHAR(50)YesOriginating Workstation IP Address
successBITNo1 = Logon Success, 0 = Logon Failure
Known Extraction Methods:

Extracted via Active Directory Web Services (ADWS), PowerShell Get-WinEvent, or Windows Event Forwarding (WEF) XML subscriptions: 

# PowerShell Extraction Script for Active Directory Events
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625,4768,4769; StartTime=(Get-Date).AddHours(-24)} | 
Select-Object TimeCreated, Id, @{N='User';E={$_.Properties[5].Value}}, @{N='SourceIP';E={$_.Properties[19].Value}} | 
ConvertTo-Json
Application Usage & Blast Radius Integration:

Used in Layer 3 Rule Engine Auditing to verify D3FEND controls D3-CredentialRotation and D3-MFA. Feeds initial entry entities (e.g. USER_JDOE, svc_sql_production) into the 3-Layer Engine Blast Radius.
