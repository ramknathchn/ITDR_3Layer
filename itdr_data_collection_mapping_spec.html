ITDR Phase 1 Data Collection & Mapping Specification

Ingest threat bulletins from email & RSS feeds, map techniques to MITRE ATT&CK, and run dynamic verification checks across 13 enterprise ecosystems.

1. Original Baseline: Systems Data Scope

1. HashiCorp Suite (Vault, Consul, Terraform Cloud)

  • Export Datasets: Vault Auditing Log (JSON client access accessor path); Consul ACL Token State; Terraform Cloud Organization Audit Trail.
  • ATT&CK Mapping Areas: T1078 (Valid Accounts) misusing static admin tokens; T1556 (Modify Auth Process) altering authentication backends; T1578 modifying infrastructure via state.
  • D3FEND Mapping Areas: D3-JUAC (Just-in-time Privilege Access) expiration of short-lived dynamic credentials; D3-CH (Credential Hardening) policy secret lifecycle enforcement.

2. BeyondTrust (PAM / EPM)

  • Export Datasets: Privileged session keystroke and command audit logs; Endpoint Privilege Management administrative elevation logs.
  • ATT&CK Mapping Areas: T1548.002 (Bypass UAC) local administrator app controls; T1021.001 (RDP) attacking hosts from jump proxies.
  • D3FEND Mapping Areas: D3-JUAC (Just-In-Time Privilege Access) role approval elevation checks; D3-PCSM (Protocol Segment Monitoring) jump session gateway auditer.

3. Data Lake (Databricks)

  • Export Datasets: Diagnostics workspace access queries; Unity Catalog metastore reads data lineage.
  • ATT&CK Mapping Areas: T1537 (Transfer Data to Cloud) exfiltrating dataset structures; T1078.004 hijacking Databricks user tokens.
  • D3FEND Mapping Areas: D3-CSA (Cloud Storage Auditing) metastore object access logging; D3-AL (Authentication Audit Logging) workspace logon audits.

4. Elastic

  • Export Datasets: Elasticsearch index cluster auditing trails; Kibana console endpoint access and security keys.
  • ATT&CK Mapping Areas: T1562.001 (Impair Defenses) disabling alerting rules or index lifecycles; T1005 (Data from Local System) mining SIEM indexes.
  • D3FEND Mapping Areas: D3-AL (Authentication Audit Logging) console logs tracking; D3-PCSM (Protocol Segment Monitoring) API endpoint security query limits.

5. AI Vector Database (Pinecone, Weaviate, Milvus, pgvector)

  • Export Datasets: Semantic search input query metrics; Namespace authorization API keys write transactions.
  • ATT&CK Mapping Areas: T1114 (Email Collection / Data Scraping) similarity scrapers pulling document embeddings; T1078 (Valid Accounts) namespace token takeover.
  • D3FEND Mapping Areas: D3-CSA (Cloud Storage Auditing) vector indexes operations checks; D3-PCSM (Protocol Segment Monitoring) vector namespace query rate-limiting.

6. Microsoft Defender for Identity (MDI)

  • Export Datasets: Domain controller threat security alerts; Identity lateral movement paths.
  • ATT&CK Mapping Areas: T1003.001 (OS Credential Dumping: LSASS) DCSync/DCShadow indicators; T1550 Golden/Silver Ticket Kerberos replays.
  • D3FEND Mapping Areas: D3-PCSM (Protocol Segment Monitoring) Active Directory domain controller authentication traffic filters; D3-UBA (User Behavioral Analytics) directory logins profiling.

7. Entra ID Protection

  • Export Datasets: Risky users status; Anomaly risk detections alerts logs (impossible travel, proxy IPs).
  • ATT&CK Mapping Areas: T1556.006 registering additional MFA mechanisms; T1078.004 valid cloud accounts anomalies.
  • D3FEND Mapping Areas: D3-MFA (Multi-Factor Authentication) step-up authentications; D3-AL (Authentication Audit Logging) sign-in failures logs.

8. Wiz.io

  • Export Datasets: VM instance package vulnerability issues; Identity graph roles permissions metrics.
  • ATT&CK Mapping Areas: T1078 valid accounts traversing service roles; T1578.002 creating container environments.
  • D3FEND Mapping Areas: D3-CSA (Cloud Storage Auditing) cloud assets vulnerability scans; D3-PCSM (Protocol Segment Monitoring) perimeter exposed node audits.

9. SentinelOne (Linux / macOS focus)

  • Export Datasets: Agent process logs; Host quarantine status alerts.
  • ATT&CK Mapping Areas: T1059.004 (Unix Shell) executing remote scripts; T1548.001 Setuid/Setgid elevations.
  • D3FEND Mapping Areas: D3-EI (Endpoint Isolation) host blocking; D3-PLA (Process Lineage Analysis) script process hierarchy audits.

10. Active Directory (On-Prem)

  • Export Datasets: Domain Controller Security Event logs; ntds.dit database changes.
  • ATT&CK Mapping Areas: T1078.002 (Domain Accounts) administrative logon abuse; T1484.001 modifying Group Policies for task persistence.
  • D3FEND Mapping Areas: D3-AL (Authentication Audit Logging) domain controllers events logs; D3-JUAC (Just-In-Time Privilege Access) privileged group tracking.

11. Entra ID (Cloud Azure AD)

  • Export Datasets: Tenant audit logs; Non-interactive and interactive sign-in records.
  • ATT&CK Mapping Areas: T1098.001 adding Oauth app keys; T1556.006 authentication bypass via MFA manipulation.
  • D3FEND Mapping Areas: D3-MFA (Multi-Factor Authentication) FIDO2 registration audits; D3-AL (Authentication Audit Logging) tenant-wide directory logons.

12. AWS

  • Export Datasets: CloudTrail API logs; IAM credentials report sheet.
  • ATT&CK Mapping Areas: T1537 exfiltrating databases via bucket syncs; T1078.004 AWS Access Keys creation.
  • D3FEND Mapping Areas: D3-CSA (Cloud Storage Auditing) S3 access logging; D3-JUAC (Just-In-Time Privilege Access) STS AssumeRole controls.

13. Azure Platform

  • Export Datasets: Activity logs management operations; Defender for Cloud alerts logs.
  • ATT&CK Mapping Areas: T1578.002 VM resource adjustments; T1098 adding subscriptions rights.
  • D3FEND Mapping Areas: D3-AL (Authentication Audit Logging) Resource Manager events; D3-MFA (Multi-Factor Authentication) management console MFA.

2. Practical Data Extraction Guide

Use the collapsible cards below to review exact extraction pathways, REST API calls, and CLI queries for each system.

UI Export Path: Vault -> Access -> Audit Devices; Terraform Cloud -> Organization Settings -> Audit Trail.

REST API Query 
# Vault Audit configuration
curl -H "X-Vault-Token: $VAULT_TOKEN" http://127.0.0.1:8200/v1/sys/audit

# Terraform Cloud audit trails
curl -H "Authorization: Bearer $TFC_TOKEN" \
  -H "Content-Type: application/vnd.api+json" \
  "https://app.terraform.io/api/v2/organizations/SCB-Org/audit-trail?page%5Bsize%5D=100"
CLI / SDK Command 
vault audit enable file file_path=/var/log/vault_audit.log

Native Download: Yes (JSON file export). Ingest Fields: time, type, request.path, request.auth.token_policies, request.auth.accessor, error.

UI Export Path: Appliance Console -> Reports -> Session Reports -> Choose dates -> Export CSV.

REST API Query 
# Oauth Token
curl -u "$CLIENT_ID:$CLIENT_SECRET" -d "grant_type=client_credentials" https://beyondtrust.example.com/api/config/v1/oauth

# Fetch logs
curl -H "Authorization: Bearer $ACCESS_TOKEN" \
  "https://beyondtrust.example.com/api/config/v1/session-monitoring?limit=50"
CLI / SDK Command 
$headers = @{ "Authorization" = "Bearer $ACCESS_TOKEN" }
$response = Invoke-RestMethod -Uri "https://beyondtrust.example.com/api/config/v1/session-monitoring" -Headers $headers
$response.items | Export-Csv -Path "C:\beyondtrust_sessions.csv"

Native Download: Yes (CSV Reports). Ingest Fields: SessionID, User, TargetHost, Duration, KeystrokeCount, ExecutedCommands, Status.

UI Export Path: Databricks Console -> Diagnostic Logs Settings -> Route output to Cloud Storage (S3/ADLS).

REST API Query 
curl -H "Authorization: Bearer $DATABRICKS_TOKEN" \
  https://adb-12345.azuredatabricks.net/api/2.0/clusters/list
CLI / SDK Command 
databricks fs cp dbfs:/cluster-logs/ /local/logs -r

Native Download: Yes (S3/Blob). Ingest Fields: time, workspaceId, userId, actionName, response, requestParams.

UI Export Path: Kibana Stack Management -> Index Management -> Select Index -> Export.

REST API Query 
curl -u elastic:$ELASTIC_PASSWORD -X GET "https://localhost:9200/_security/api_key?owner=true"
CLI / SDK Command 
tail -f /var/log/elasticsearch/elasticsearch_audit.json

Native Download: Yes (Kibana dashboard export). Ingest Fields: timestamp, event.type, user.name, elasticsearch.audit.layer, action, origin.address.

UI Export Path: Pinecone UI shows namespaces metrics charts; no native query logs download button.

REST API Query 
curl -H "Api-Key: $PINECONE_API_KEY" https://controller.us-east1-gcp.pinecone.io/databases
CLI / SDK Command 
psql -h localhost -U postgres -d vector_db -c "
SELECT query, calls, total_exec_time 
FROM pg_stat_statements 
WHERE query LIKE '%<=>%' OR query LIKE '%<->%' OR query LIKE '%<#>%';
" -o pgvector_audit.txt

Native Download: No. Ingest Fields: timestamp, namespace, api_key_id, operation_type, top_k, query_vector_hash.

UI Export Path: Defender portal -> Settings -> Identities -> Security Alerts -> Click Export alerts CSV.

REST API Query 
curl -H "Authorization: Bearer $MS_GRAPH_TOKEN" \
  "https://graph.microsoft.com/v1.0/security/alerts?\$filter=vendorInformation/provider+eq+'Defender+for+Identity'"
CLI / SDK Command 
Get-MgSecurityAlert -Filter "vendorInformation/provider eq 'Defender for Identity'" -Property "id,title,severity,createdDateTime,compromisedEntity" | ConvertTo-Json > mdi_alerts.json

Native Download: Yes (CSV Alert lists). Ingest Fields: AlertId, Title, Severity, CompromisedEntity, Classification, Evidence, CreatedTime.

UI Export Path: Entra admin center -> Protection -> Identity Protection -> Risky Users -> Click Export.

REST API Query 
curl -H "Authorization: Bearer $MS_GRAPH_TOKEN" \
  "https://graph.microsoft.com/v1.0/identityProtection/riskDetections?\$filter=riskLevel+eq+'high'"
CLI / SDK Command 
Get-MgIdentityProtectionRiskDetection -Filter "riskLevel eq 'high' and riskState eq 'atRisk'" -All | ConvertTo-Json > risky_detections.json

Native Download: Yes (CSV). Ingest Fields: id, riskState, riskLevel, riskDetail, userDisplayName, ipAddress, location.

UI Export Path: Wiz Dashboard -> Issues -> Select Identity Risks -> Export Issue spreadsheet as CSV.

REST API Query 
curl -X POST -H "Authorization: Bearer $WIZ_TOKEN" -H "Content-Type: application/json" \
  -d '{"query": "query { issues(first: 50) { nodes { id title severity status } } }"}' \
  https://api.us12.wiz.io/graphql
CLI / SDK Command 
wizcli auth login --client-id $WIZ_ID --client-secret $WIZ_SECRET
wizcli issue list --format json > wiz_issues.json

Native Download: Yes (CSV). Ingest Fields: id, name, status, severity, resourceType, targetEntity, effectivePermissions.

UI Export Path: Sentinels -> Endpoints -> Filter by OS -> Actions -> Export CSV.

REST API Query 
curl -H "Authorization: ApiToken $S1_TOKEN" \
  https://console.sentinelone.net/web/api/v2.1/threats?limit=50
CLI / SDK Command 
sentinelone-cli threat query --status active --output json > s1_threats.json

Native Download: Yes (CSV/JSON). Ingest Fields: threatId, createdAt, agentName, filePath, commandLine, threatName, resolved.

UI Export Path: DC -> Event Viewer -> Windows Logs -> Security -> Save All Events As EVTX.

CLI / SDK Command 
Get-WinEvent -FilterHashtable @{LogName='Security'; ID=@(4624,4720)} -MaxEvents 100 | 
  Select-Object TimeCreated, Id, MachineName, Message | 
  Export-Csv -Path "C:\ad_security_events.csv" -NoTypeInformation

Native Download: Yes (EVTX files). Ingest Fields: EventID, TimeCreated, TargetUserName, TargetDomainName, IpAddress, LogonType, Status.

UI Export Path: Entra admin center -> Monitoring & health -> Sign-in logs -> Download JSON.

REST API Query 
curl -H "Authorization: Bearer $MS_GRAPH_TOKEN" \
  "https://graph.microsoft.com/v1.0/auditLogs/signIns?\$filter=createdDateTime+ge+2026-07-27T00:00:00Z"
CLI / SDK Command 
Get-MgAuditLogSignIn -Filter "createdDateTime ge 2026-07-27T00:00:00Z" -All | ConvertTo-Json > entra_signins.json

Native Download: Yes (JSON/CSV). Ingest Fields: id, createdDateTime, userPrincipalName, appDisplayName, clientAppUsed, ipAddress, status.

UI Export Path: AWS Console -> CloudTrail -> Event history -> Download JSON.

CLI / SDK Command 
aws cloudtrail lookup-events \
  --lookup-attributes AttributeKey=EventName,AttributeValue=ConsoleLogin \
  --max-results 50 --output json > aws_logins.json

Native Download: Yes (JSON). Ingest Fields: eventID, eventTime, userIdentity.arn, eventName, sourceIPAddress, requestParameters.

UI Export Path: Subscription Monitor Portal -> Activity Log -> Download as JSON.

REST API Query 
curl -H "Authorization: Bearer $AZ_TOKEN" \
  "https://management.azure.com/subscriptions/$SUB_ID/providers/microsoft.insights/eventtypes/management/values?api-version=2015-04-01"
CLI / SDK Command 
az monitor activity-log list --offset 2h --output json > azure_activity.json

Native Download: Yes (JSON). Ingest Fields: eventId, eventTimestamp, caller, operationName.value, status.value, resourceId.

3. Minimum Record Metadata Standard

All data ingestion endpoints must validate and append these 12 metadata headers to ensure data lineage audit integrity.

Metadata Field Data Type Mapping Description Example Value
tenant_or_org_id VARCHAR(100) Unique ID of the tenant or organization. T-US-SCB-098
platform_name VARCHAR(100) Name of the source platform. HashiCorp_Vault
source_table_or_endpoint VARCHAR(250) Source log table or API endpoint path. vault.audit.logs
record_primary_key VARCHAR(100) Unique record key inside the system. EVT-09876-2026
record_version_or_etag VARCHAR(50) Record revision tracking hash. W/"123-abc"
event_or_config_timestamp VARCHAR(100) Time the actual security event occurred (ISO 8601). 2026-07-27T16:30:00Z
collector_timestamp_utc VARCHAR(100) Time the collector harvested this record. 2026-07-27T16:35:10Z
collector_method VARCHAR(50) Collection route (e.g. API, CLI, manual download). API_Graph
data_owner VARCHAR(100) Department or security owner responsible for the dataset. Identity_SOC_Group
environment_tag VARCHAR(50) Targeted environment marker (Production, Staging). Production
region VARCHAR(50) Geographic data center location. us-east-1
integrity_hash VARCHAR(64) SHA-256 validation hash of the record data. f2ca1a6136e259e2...
