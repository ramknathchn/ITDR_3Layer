ITDR Blast Radius & Infrastructure Mapping Guide

Detailed technical overview of bank systems classification and data source origins for path analysis.

1. Systems Classification Framework

Tier 0 Assets Crown Jewels
  • SG-DC-01 & HK-DC-01

    Active Directory Domain Controllers managing network credentials.

  • scb-oracle-prod

    Core Banking database housing transaction registries.

  • scb-swift-gateway

    SWIFT Transfer Payment node managing external wires.

Tier 1 Assets Management & Secrets
  • HashiCorp Vault Production

    Secrets management vaulting active API and keys.

  • scb-cust-records-prod

    AWS S3 Bucket holding customer documents shard.

  • HK-SRV-EKS-01

    EKS Kubernetes node managing containerized APIs.

Tier 2 Assets Endpoints & General
  • Employee Workstations

    Windows & macOS local computers run by general users.

  • Standard Identities

    General non-privileged employee email user accounts.
